용심리 AutoCut - 시작 안내

1. Windows 10/11 64비트에 Python 3.12 또는 3.13 64비트를 설치하세요.
   https://www.python.org/downloads/windows/
   설치 화면의 Add python.exe to PATH를 체크하세요.
2. ZIP을 모두 압축 푼 뒤 초기설치.cmd를 더블클릭하세요.
   처음 한 번 무료 라이브러리를 인터넷으로 설치합니다.
3. 용심리 AutoCut.cmd를 더블클릭하세요. 다음부터는 이것만 실행합니다.

앱 사용 순서
영상 불러오기 → 1차 컷 분석 → 자를 구간 확인 → MP4 저장

기본 설정은 2.5초 이상의 긴 무음을 약 1초로 줄입니다.
작은 목소리나 숨이 포함된 후보는 재생 후 체크를 해제하세요.
앞뒤 폰 조작 의심 장면은 자동으로 선택하지 않습니다.
앞뒤 화면·직접 조정 탭에서 실제 프레임을 보고 재생한 뒤 직접 지정하세요.
이 탭의 아래쪽 수동 조정 항목은 창 높이에 따라 스크롤해 볼 수 있습니다.

분석·저장은 인터넷 연결이나 유료 API 없이 PC 안에서만 실행됩니다.
의미 분석, 반복 대사 삭제, 배속, 자막, 효과, 색보정을 하지 않습니다.
원본과 기존 결과를 덮어쓰지 않습니다. MP4 옆 타임맵 JSON도 함께 보관하세요.
